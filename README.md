# FITIFY – Fitness Product Landing Page

## Project Overview

FITIFY is a simple fitness product landing page developed using HTML5 and CSS3. The website showcases fitness supplement products through a basic product display layout, along with navigation sections, a search input, About Us and Contact Us sections.

The main objective of this project was to understand website structure, CSS styling, product card layouts and basic frontend design.

## Features

- Fitness product landing page.
- Navigation bar with Home, About Us and Contact Us sections.
- Search input field (UI only).
- Product display cards with images and descriptions.
- CSS hover effects on navigation items and product cards.
- About Us section.
- Contact Us section.
- Simple black-and-white website design.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and layout.
- CSS Hover Effects – Interactive visual styling.
- CSS Inline-block – Product card arrangement.
